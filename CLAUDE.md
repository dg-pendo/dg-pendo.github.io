# pm-docs

This repository contains working PM documents for **Agent Analytics** — an AI-powered product analytics tool built by Pendo to help users measure and improve their AI agents.

## About This Repo

This is a personal working repository for a Product Manager at Pendo. It stores in-progress and reference documents across the full PM workflow.

## Contents

- **PRDs** — Product requirements documents for Agent Analytics features and initiatives
- **Research** — User research, competitive analysis, and market insights
- **Analysis** — Data analysis, metrics reviews, and performance deep-dives
- **Meeting Notes** — Notes from customer calls, cross-functional syncs, and stakeholder meetings
- **Strategy Docs** — Roadmap thinking, positioning, and longer-horizon planning

## About Agent Analytics

Agent Analytics is Pendo's AI-powered product analytics offering focused on helping teams understand and improve the performance of their AI agents. It provides instrumentation, measurement, and insight tooling so product teams can answer questions like:

- Are users getting value from AI features?
- Where do AI agents fail or underperform?
- How does AI usage correlate with retention and outcomes?

## Working With This Repo

Documents here are working drafts unless marked otherwise. They may be incomplete, in review, or actively evolving. Use git history to track changes over time.

When helping with documents in this repo:
- Maintain the voice and framing appropriate for internal Pendo PM communication
- Understand the audience: engineering, design, data, leadership, and customers
- Agent Analytics context: AI agent instrumentation, LLM observability, product analytics for AI-powered features
- Flag assumptions and open questions rather than resolving them silently
